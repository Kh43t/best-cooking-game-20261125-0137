**Warung Senja — Dapur Kilat**: a complete, original cooking game. Run a sunset Indonesian street-food warung: take orders off the board, chop chicken and vegetables on the board, fry nasi goreng and mie goreng in the wok, grill sate ayam, plate the dish and serve it before the customer's patience runs out. Three-minute shifts, combo bonuses, and a rush hour in the last 30 seconds. All art is drawn in code on canvas and all sound and music is synthesised live with WebAudio — no external files, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080 in desktop Chrome
```

Or serve `game/` with any static server and open `game/index.html`. Play with mouse and keyboard: `1–6` grab ingredients, `C` chop, `Space` serve, `P` pause, `M` mute.
